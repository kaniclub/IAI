# Iaigiri

右クリックで発動する居合斬りのセカンダリーアクションを追加する MOD です。

## 概要

Iaigiri は、Stardew Valley に右クリックで使える居合斬りを追加する MOD です。  
カマには居合のセカンダリーアクションを追加し、ガード系の剣では既存のセカンダリーアクションを居合に置き換えます。

## 主な特徴

- 右クリックで居合斬りを発動
- 半径を設定可能
- 設定ディレイ後に効果を一括適用
- モンスターへのダメージに対応
- Generic Mod Config Menu によるゲーム内設定に対応

## 動作要件

- Stardew Valley 1.6 以降
- SMAPI 4.0.0 以降

## 任意

- Generic Mod Config Menu  
  導入すると、ゲーム内から設定を変更できます。

## 導入方法

1. SMAPI を導入します。
2. Iaigiri をダウンロードします。
3. 展開したフォルダを Stardew Valley の `Mods` フォルダに入れます。
4. ゲームを起動します。
